# Marketing site · UI kit

A first-principles recreation of `bobabear.in`-style marketing surfaces built strictly against the Boba Bear design system. **No real product code or Figma was provided** — when those land, re-run this kit and replace the screens.

## Components
| File | Purpose |
|---|---|
| `index.html` | Click-through demo: hero → menu → drop → artists → footer |
| `Nav.jsx` | Glass top nav with marquee strip |
| `Hero.jsx` | Editorial hero with display type + protection gradient |
| `MenuStrip.jsx` | Horizontal scroll of product cards with category chips |
| `DropFeature.jsx` | Drop-04 spotlight with Aurora stage |
| `ArtistGrid.jsx` | Artist collab tiles |
| `Footer.jsx` | Sitemap + IG handle |

## Surfaces represented
- Homepage
- Drop page (anchored in homepage as feature block)
- Menu page (the menu strip is the inline tease; full menu would be a separate route)
- Artists page (also anchored as feature block)

## How to read this
Open `index.html`. Scroll the page top → bottom. The nav glass-blurs over content. The Aurora marquee runs continuously. Cards lift on hover.
